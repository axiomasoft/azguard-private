# P4.10 — UUID morph index name: репродукция и владелец исправления (2026-07-22)

> Слой 1. Read-only разбор эскалации P4.10 на committed tree `3411f75`.
> Вердикт: repository-grounded; production-код не менялся.

## Воспроизведение

```text
COMPOSER_PROCESS_TIMEOUT=900 MYSQL_PORT=23306 composer test:mysql -- --filter='creates the scopes unique index when the morph type is uuid'
```

MySQL останавливает `Schema::create()` в `tests/Feature/MorphTypeTest.php:64` с
`SQLSTATE[42000] 1059`: автоматически сгенерированное имя
`uuid_morph_test_model_has_scopes_scope_entity_type_scope_entity_id_index` длиннее 64
символов. Timeout `900` не является исправлением: он лишь позволил увидеть детерминированный
DDL-дефект вместо Composer timeout `300` на полном лейне.

## Классификация владельца

Fixture не произвольна: она моделирует production migration
`000000_create_az_guard_tables.php`, которая вызывает `MorphColumns::add()` для `model` и
`scope_entity`. При UUID `MorphColumns::add()` вызывает Laravel `uuidMorphs()` /
`nullableUuidMorphs()` без `$indexName`; Blueprint строит имя из configurable table name,
columns и `index` (`vendor/laravel/framework/src/Illuminate/Database/Schema/Blueprint.php:1639-1670,1754-1765,1797-1811`).
Значит сокращение fixture table names сделало бы MySQL-test зелёным, но скрыло бы тот же
production-risk для длинных `az-guard.table_names`.

## Минимальное исправление

Отдельный P4.12 владеет `MorphColumns`: он передаёт deterministic короткие index names для
каждой morph-пары, зависящие от table name так, чтобы не коллидировать между таблицами в
PostgreSQL schema и оставаться короче 64 символов на MySQL. Тест сохраняет длинные fixture
names, использует `MorphColumns::add()` вместо прямых Blueprint UUID helpers и доказывает
создание обеих morph-indexes на SQLite/PostgreSQL/MySQL.

P4.10 остаётся интеграционным gate: только после P4.12 он повторяет полный MySQL-suite с
`COMPOSER_PROCESS_TIMEOUT=900`, затем выполняет CI/docs deliverables. P3/API snapshot не
затрагиваются: меняется internal schema helper и тестовое доказательство, не public `@api`
surface. RAG:— (repo-grounded: files/lines above; root/semver-policy.md §1–4).
