### P4.1 — Разделить registry и request/job state

**Intent:** Убрать request/job-local current panel из long-lived registry, сохранив текущий public manager/Facade contract.
**Why:** RAG:— F11 подтверждает singleton mutable state, а F15 — отсутствие auth-model recursion guard. Existing queue reset и sync exemption уже правильны и не должны быть переизобретены. Official Laravel scoped lifecycle подтверждает request/job reset, но не fiber isolation. D7 фиксирует минимальный контракт.
**Scope Included:** Internal scoped current-panel holder; default manager delegation; nested restore on success/exception; Octane/queue/sync semantics; configured custom manager compatibility; auth provider model early guard before `Auth::check()`.
**Scope Excluded:** New public PanelContext API; making the panel registry request-scoped; changing `AzGuardManagerInterface`; coroutine/fiber-local promise; context-package redesign; deleting lifecycle listeners needed by custom managers; broad Eloquent scope audit.
**Inputs:** terminal GREEN `phases/P1/P1.2.state.md` · `plan.md` · `phases/P4/P4.md` · `findings/verification.md` F11/F15 · `decisions/D7-p4-runtime-validation-and-bounded-review.md` · `research/P4-design.md` · `research/P4-design-rag.md` · `artifacts/P4-design/examples.md`.
**Files:** new internal `packages/core/src/Runtime/CurrentPanelState.php` · `packages/core/src/AzGuardManager.php` · `packages/core/src/AzGuardServiceProvider.php` · `packages/core/src/Http/Middleware/SetCurrentPanel.php` · `packages/core/src/Concerns/HasScopedRoles.php` · new `tests/Feature/CurrentPanelLifecycleTest.php` and `tests/Feature/AuthModelScopedRoleGuardTest.php` · affected `SetCurrentPanelMiddlewareTest.php` / `JobProcessingPanelResetTest.php`.
**Required Reads:** 1) `packages/core/src/AzGuardManager.php` 2) `packages/core/src/AzGuardServiceProvider.php` 3) `packages/core/src/Contracts/AzGuardManagerInterface.php` 4) `packages/core/src/Http/Middleware/SetCurrentPanel.php` 5) `packages/core/src/Concerns/HasScopedRoles.php` 6) `packages/context/src/AzGuardContextServiceProvider.php` 7) `tests/Feature/SetCurrentPanelMiddlewareTest.php` 8) `tests/Feature/JobProcessingPanelResetTest.php`.
**Implementation Rules:** Bind one internal `CurrentPanelState` as scoped. The default singleton manager keeps registered panels but delegates only `currentPanel()` / `setCurrentPanel()` to the currently resolved holder; do not change their signatures or the configured manager class seam. `SetCurrentPanel` captures the previous panel and restores that exact value in `finally`, never unconditional null. Retain lifecycle reset hooks for configured custom managers and the existing sync-driver exemption; default behavior may rely on scoped reset but must stay idempotent with hooks. Before any `Auth::check()`/`Auth::user()` in the HasScopedRoles global scope, return when the queried model is an effective configured auth-provider model so loading the user cannot recurse through its own scope. Do not claim fiber safety.
**Code Guidance:** Keep the holder as a tiny final internal state object; no registry abstraction or stack API is required. Resolve it lazily inside default manager methods so a singleton manager does not capture one scoped instance forever. For the auth guard, derive provider model classes from current auth config and compare model classes without instantiating/authenticating a user.
**Validation:** 1) nested A→B restores A and outer null after success and exception; 2) forgetting scoped instances yields a fresh null state while registered panels remain; 3) Octane `RequestReceived` and non-sync `JobProcessing` clear state, sync preserves the enclosing panel; 4) configured custom manager still receives the unchanged set/current calls; 5) auth-provider model query using HasScopedRoles completes with bounded queries and does not call back into authentication recursively; non-auth scoped entities still receive their scope; 6) `vendor/bin/pest tests/Feature/CurrentPanelLifecycleTest.php tests/Feature/AuthModelScopedRoleGuardTest.php tests/Feature/SetCurrentPanelMiddlewareTest.php tests/Feature/JobProcessingPanelResetTest.php tests/Feature/Context/ContextScopingTest.php`; 7) changed-file Pint, PHPStan and `git diff --check`.
**Deliverables:** Request/job-scoped current panel behind unchanged manager/Facade API; correct nested restore and sync semantics; F15 recursion guard; focused lifecycle regressions; no separate review stage.
