### P2.8 — FolderSource: discovery папки панели, атрибуты, pairing политик

**Intent:** Сделать папку панели источником: `FolderSource` находит enum прав, политики, роли и области в утверждённой структуре `Permissions/<Group>` с параллельными корнями, превращает атрибуты в определения каталога с явным режимом authority, связывает политики с правами только через `#[Decides]` и даёт одинаковый результат при живом автопоиске и из кэша.
**Why:** RAG:— D56, D72 (корни по типам классов, группы вложенные; pairing: same-root + same-relative-group, один enum и одна непривязанная policy; несколько кандидатов → `InvalidPolicyStructureException`; каждый метод политики обязан иметь `#[Decides(enumCase)]`, вывода по имени нет; registry — enum FQCN и `PermissionKey`; roots сохраняют происхождение; `Resources` и корень панели не сканируются; discovery config и roots входят в fingerprint; live и cached discovery дают одинаковые bindings); 05 §4.1 (`FolderSource::make()`, `folders(...)`), §6 (роли), §7 (`Resource`, `Describe`, `RequiresGrant`, `PolicyOnly`, `GrantedToAll`, `PolicyFor`, `Decides`), §12 (режим на enum или case, case переопределяет enum; оба или ни одного → `DefinitionException`; `PolicyBinding` объявляет ожидаемое действие, метод обязан нести `#[Decides]`); D73 (enum из `permissions([...])` входят в `FolderSource`; явный `FolderSource` настраивает встроенный один раз, несколько — конфликт); 07 §2 `discovery`, §6 (корни разные и не пересекаются); 04 §4; V55 (вариант `discover`), V78, V79, V81 (имя модуля под префиксом панели), V102, V106; D10 (у плагина нет префикса ключей); D8 п.1, п.2, п.7.

**Implementation Rules:** Discovery root — каталог файла провайдера панели (namespace — namespace провайдера) плюс каждый `discover(path, namespace)`; root несёт происхождение записи (провайдер или `plugin:<id>` с префиксом). Имена корней — из `AzGuardConfig::discovery()` (`permissions`, `policies`, `roles`, `scopes`, `abilities`, `queries`, `shared`) или `FolderSource::folders(...)`; корни `permissions` и `policies` совпали или вложены друг в друга → `InvalidConfigurationException`. Сканируются только `<root>/<Permissions>/**` (string-backed enum), `<root>/<Policies>/**` (классы), `<root>/<Roles>/*` (наследники `BaseRole`), `<root>/<Scopes>/*` (`AssignmentScopeDefinition`); сам root, `Resources/`, прочие каталоги и `Sources/` в корне как группа прав не сканируются; `Permissions/Sources/` — обычная группа. Класс определяется по PSR-4 из пути и namespace root; файл без ожидаемого класса или абстрактный класс пропускается; порядок — сортировка путей, результат не зависит от порядка файловой системы. Enum: значение case — локальное имя по грамматике; режим — `#[RequiresGrant]`/`#[PolicyOnly]` на case, иначе на enum; оба атрибута на одном элементе или ни одного итогового режима → `DefinitionException`; `#[Describe]` даёт `label`/`group`/`description`, без него `label` — null, `group` — `#[Resource(label:)]` или относительный путь группы; `#[Resource(model:)]` → `resourceModel`. Enum из `permissions([...])` добавляются к найденным; повтор FQCN идемпотентен. Роли — найденные плюс `roles([...])`; проверки ключей и прав выполняет компиляция P2.5. Привязка политик в пределах одного root: класс с `#[PolicyFor(Enum::class)]` связан с этим enum; без `PolicyFor` — один enum группы `Permissions/<rel>` и одна не привязанная явно policy в `Policies/<rel>` образуют пару; несколько кандидатов без точной привязки → `InvalidPolicyStructureException` с путями; группы двух разных roots с одинаковым относительным путём не склеиваются. Метод политики участвует только с `#[Decides(case|имя)]`; имя метода свободно; два метода на одно право или `Decides` на право чужого enum без `PolicyFor` → `InvalidPolicyStructureException`; публичный метод без `Decides` привязки не создаёт. `policies([...])`: `PolicyBinding` либо class-string политики (её привязки берутся из `Decides`); объявленный `PolicyBinding::for(action, class)`, у класса которого нет ровно одного метода с `#[Decides(action)]`, → `DefinitionException`; необязательное veto для `RequiresGrant` подключается только такой явной привязкой либо pairing группы. Итог — `PolicyBinding` с правом, классом и найденным методом в метаданных каталога; дубли и PolicyOnly без привязки ловит P2.5. Префикс плагина применяется по происхождению root одинаково к именам прав enum, ключам ролей, строкам `Role::permissions()` и правам привязок. Явный `FolderSource` в `permissions([...])` один раз заменяет неявный; два явных → `DefinitionException`. `FolderSource::id()` — `folder`, `isDynamic()` — false. `Shared/` (соседний каталог панелей с именем из `discovery.shared`) панелью не становится: из него и из `Sources/` панелей классы с `#[AsSource]` передаются в `SourceManager`. Кэш: `azguard:catalog:cache` дополнительно сохраняет найденные классы по roots; при актуальном снимке файловая система не сканируется. В отпечаток входят roots, имена корней и sha256 содержимого найденных файлов.
