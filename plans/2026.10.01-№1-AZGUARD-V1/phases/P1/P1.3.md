### P1.3 — Значения решения: AccessRequest, Decision, Grant, токены, PermissionSet

**Intent:** Ввести неизменяемые значения запроса и ответа «можно ли»: запрос с явным tenant/context/resource, решение с согласованными effect/reason и типизированным свидетельством состояния, выдачу и вклад роли с владельцем и сроком, набор шаблонов субъекта.
**Why:** RAG:— 05 §5 (сигнатуры), D17 (Allow/Deny/NotApplicable + причина + версия состояния; ошибка = отказ), D20 (`RestrictionResult` pass/deny), D61 (RoleContribution — отдельное значение, условия одной строки), D62/08 (origin — владелец вклада), D83 (BeforeResult только Continue/Deny; `CodeStateToken` отделён от `StateToken`); V120 (часть P1); D6 п.1–2 (`RoleContribution` здесь; `Explanation` → P4.10, `toGateResult()` → P4.11).
**Scope Included:** `AzGuard\Kernel\Decision\`: `AccessRequest` (`for`, `inTenant`, `on`, `inScope`, `traced`; геттеры `subject`, `permission`, `tenant`, `context`, `resource`, `isTraced`), `Effect`, `DecisionReason` (все кейсы 05 §5 с теми же значениями), `Decision` (фабрики `allow`/`deny`/`notApplicable`, `allowed()`), `DecisionSet` (`Countable`, `IteratorAggregate`, `get`, `states`), `Grant`, `RoleContribution`, `RestrictionResult` (`pass`, `deny(reason)`, `denied`, `reason`), `BeforeResult` (`Continue`, `Deny`), `PermissionAuthority` (string-backed `Policy='policy'`, `Grants='grants'`; только кейсы — семантика в P1.6), `CodeStateToken`, `StateToken`. `AzGuard\Kernel\Permissions\PermissionSet` (`patterns`, `covers`, `validUntil`).
**Scope Excluded:** `Explanation` (P4.10), `Decision::toGateResult()` (P4.11), `GrantCondition` (P4.1), сравнение/свежесть токенов и version fence (P4.8), семантика `PermissionAuthority` (P1.6), проверка `fields()` по схеме полей (P3.3/P5.2).
**Inputs:** `plan.md` · `phases/P1/P1.md` · `decisions/D6-p1-dependency-closure.md`. Код P1.1–P1.2 (`Kernel\Identity`, `Kernel\Grammar`, `Exceptions`) читается из рабочего дерева после их закрытия.
**Files:** `packages/core/src/Kernel/Decision/{AccessRequest,Effect,DecisionReason,Decision,DecisionSet,Grant,RoleContribution,RestrictionResult,BeforeResult,PermissionAuthority,CodeStateToken,StateToken}.php` · `packages/core/src/Kernel/Permissions/PermissionSet.php` · `tests/Unit/Kernel/Decision/*Test.php` · `tests/Unit/Kernel/Permissions/PermissionSetTest.php` · `CHANGELOG.md`.
**Required Reads:** 1) `audits/2026-09-29-audit/opus/05-php-api.md` §5 2) `audits/2026-09-29-audit/opus/02-decisions.md` (только решения d17, d20, d61, d62, d83) 3) `audits/2026-09-29-audit/opus/09-authorization-semantics.md` §2 (только состав входов/выходов решения) 4) `audits/2026-09-29-audit/opus/08-data-model-and-migration.md` (строки про origin/fields, I9–I12) 5) `decisions/D6-p1-dependency-closure.md`.
**Implementation Rules:** Все значения `final readonly`; изменения только withers-клонами. `AccessRequest::on(null, …)` — context не задан (резолвер решит позже); `AssignmentScopeRef::global()` — явный global; `inTenant` не сбрасывается последующим `on`; `inScope` задаёт оба. `resource` — `?object` без интерпретации. `Decision`: инвариант effect/reason, нарушение — `InvalidArgumentException` (ошибка программиста, не identity): Allow ⇒ reason ∈ {Granted, SuperAdmin, Policy}; NotApplicable ⇒ reason = NotApplicable; Deny ⇒ reason ∉ {Granted, SuperAdmin, NotApplicable}. `state` — `CodeStateToken|StateToken`, `scope` — `AccessScope`, `component` — ?string, `grants` — `list<Grant>`. `Grant` и `RoleContribution`: `source` и `origin` проверяются `IdentityCodec::assertSourceLabel`, origin по умолчанию `IdentityCodec::DEFAULT_ORIGIN`; у `Grant` с ролью панель роли = панель шаблона, иначе `InvalidArgumentException`; `fields` — `array<non-empty-string, scalar|null|array>` рекурсивно без объектов (кэшируемость и неизменяемость), иначе `InvalidArgumentException`; `activeAt(DateTimeImmutable $now): bool` — `expiresAt === null || expiresAt > now` (Kernel не зовёт `now()`). `RestrictionResult::deny` требует snake_case reason. `CodeStateToken(panel, buildId, fingerprint)` и `StateToken(storageId, panel, incarnation, version ≥ 0, generation ≥ 0, fingerprint)` — непустые строки, панель по грамматике, `equals`. `DecisionSet::states()` — ключи через `IdentityCodec::compose(['code', panel, buildId])` и `compose(['storage', storageId, panel])`, без конкатенации. `PermissionSet` — дедупликация шаблонов по `full()`, `covers` = любой шаблон покрывает ключ, `validUntil` — ?DateTimeImmutable. Дополнительные публичные методы сверх перечисленных — только если нужны тесту/следующему пункту, с записью в findings. Kernel без Laravel.
