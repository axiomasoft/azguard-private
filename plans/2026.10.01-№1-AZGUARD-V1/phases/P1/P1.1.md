### P1.1 — Kernel\Identity: ключи, ссылки, IdentityCodec

**Intent:** Сделать идентичность права, роли, субъекта, тенанта, области и инициатора одной и однозначной: readonly значения с проверкой при создании и `IdentityCodec`, который строит составные ключи JSON-массивом и digest без склейки строк; дефект P07 становится невозможным.
**Why:** RAG:— D07 (alias `^[a-z0-9][a-z0-9_.-]{0,127}$`, id ≤ 64 ASCII без whitespace/control, `7 ≡ '7'`, `'007'` — другая identity, `type:id`/`global`, вид ref в сериализации, версия кодека в cache/state); D08 (system actor `azguard.system`, id null, reason); D59 (global context внутри tenant ≠ global tenant); probe P07 (C01), V01/V02/V04/V86; D6 п.1–2 (TenantRef/AccessScope здесь, `prefixed()` — P2.2, host keys — P3).
**Scope Included:** `AzGuard\Kernel\Identity\`: `PermissionKey` (`of`, `parse`, `panel`, `local`, `full`, `equals`, `Stringable`/`JsonSerializable` → `full()`), `PermissionPattern` (`of`, `panel`, `local`, `full`, `covers(PermissionKey)`, `isExact`, `equals`), `RoleKey` (`of`, `parse`, `panel`, `key`, `full`, `equals`), `SubjectRef` (`of`, `type`, `id`, `key`, `equals`), `TenantRef` и `AssignmentScopeRef` (`of`, `global`, `isGlobal`, `key`, `type`, `id`, `equals`), `AccessScope` (`in(TenantRef, ?AssignmentScopeRef = null)`, public readonly `tenant`/`context`, `equals`), `AnyAssignmentScope` (`all()`), `ActorRef` (`SYSTEM_TYPE`, `of(type, id, ?reason)`, `system(?reason)`, public readonly `type`/`id`/`reason`), `IdentityCodec` (версия, канон id, проверка alias и строки источника/origin, tagged-кодирование/декодирование ссылок, составной ключ и digest). Property/табличные тесты V01, V02 (часть значений), V04 (уровень кодека), V86 (Kernel-часть); регрессия P07; V02-отказы значений (`*`/`**`) в unit-тестах.

**Implementation Rules:** Все классы `final readonly`, приватный конструктор, создание только фабриками с проверкой. Type alias — `^[a-z0-9][a-z0-9_.-]{0,127}$` (двоеточие запрещено); у `AssignmentScopeRef` нарушение → `InvalidAssignmentScopeException`, у `SubjectRef`/`TenantRef`/`ActorRef` → `InvalidIdentityException` (D6 п.4). Id: `int` → десятичная строка; `string` — непустая, ≤ 64 байт, только печатный ASCII `0x21–0x7E` (без whitespace/control/не-ASCII), без канонизации (`'007'` ≠ `'7'`). `global()` — отдельная форма: `type()`/`id()` = null, `key()` = `global`; `of('global', …)` допустим и не равен `global()` (различие в tagged-кодировании). `key()` = `type:id`, однозначен, так как type без `:`. `PermissionKey::of` проверяет панель и локальный ключ; `parse` — полный; `PermissionPattern::of` — шаблон, `covers` = совпадение панели и `PatternMatcher`. `AccessScope::in` нормализует `null` в `AssignmentScopeRef::global()`. `ActorRef::system` — type `azguard.system`, id null; `of` запрещает type `azguard.system` (только через `system`). `IdentityCodec`: константа `VERSION = 1`; `DEFAULT_ORIGIN = 'manual'`; `assertTypeAlias`, `assertSourceLabel` (`^[a-z0-9][a-z0-9_.:-]{0,127}$` для source/origin, D6); `encode(object $ref): list<string|null>` — tagged-массив с видом (`permission`, `pattern`, `role`, `subject`, `tenant`, `context`, `scope`, `actor`); `decode(list) → ref` обратна; `compose(list<mixed>): string` — `json_encode` с `JSON_THROW_ON_ERROR|JSON_UNESCAPED_SLASHES|JSON_UNESCAPED_UNICODE`, первым элементом версия кодека; `digest(list<mixed>): string` = `sha256(compose(...))`. Никакой конкатенации без границ. Kernel без Laravel. P07: `tests/Regression/P07Test.php` повторяет сценарий spec (`of('workspace:a', 7)` → исключение; `of('w', 7) ≡ of('w', '7')`; ключи `('workspace','a:7')` и `('workspace','a')` различны; digest составных ключей различен) и обновляет `Status: covered:`. V02 в `tests/Unit/Kernel/Identity/PermissionKeyTest.php`: `PermissionKey::of('admin','*')`, `PermissionPattern::of('admin','**')` → `InvalidPermissionKeyException` (P14Test принадлежит P1.2 и не меняется).
