### P1.2 — Грамматика имён и шаблонов

**Intent:** Дать одну чистую грамматику прав, шаблонов выдачи, id панели и ключа роли с сопоставлением шаблонов, на которую опираются все значения Kernel; голые `*`/`**` невозможны как ключ и как шаблон.
**Why:** RAG:— D18 (сегмент, ≥ 2 сегментов, ≤ 255, `panel:local`, `*` один сегмент, `**` глубже, голые запрещены, сменяемого matcher нет); D06 и `02` D-раздел ролей (id панели и ключ роли `^[a-z0-9][a-z0-9-]{0,63}$`); D37 (база исключений); probe P14 (`tests/Regression/specs/P14.md`), V02/V03.
**Scope Included:** `AzGuard\Kernel\Grammar\PermissionGrammar` (final, static, без состояния): проверки и предикаты для сегмента, локального ключа, полного ключа `panel:local` с разбором, шаблона, id панели, ключа роли; константы ограничений. `AzGuard\Kernel\Grammar\PatternMatcher` (final, static): `covers(string $pattern, string $local): bool` по сегментам. `AzGuard\Exceptions\AzGuardException` (abstract, `code(): string`), ветки D37 как abstract-классы `ConfigurationException`, `DefinitionException`, `ChangeException`, `AuthorizationEngineException`, `StorageException`, `PluginException`; `InvalidIdentityException` (не abstract, код `invalid_identity`, D6) и её наследники `InvalidPanelIdException` (`invalid_panel_id`), `InvalidPermissionKeyException` (`invalid_permission_key`), `InvalidRoleKeyException` (`invalid_role_key`), `InvalidAssignmentScopeException` (`invalid_context`). Табличные тесты грамматики и сопоставления; Kernel-регрессия P14.
**Scope Excluded:** value objects (`PermissionKey`, `PermissionPattern`, `RoleKey` — P1.1); грамматика type alias/id ссылок (P1.1, D07); проверка `permissions()` роли против каталога (P2.5/P2.8); сквозной сценарий `grantPermission('*')`/`isSuperAdmin()` (V17/V22 в P4.7/P5.2); остальные исключения 05 §10 (вводят owning items).

**Implementation Rules:** Сегмент `^[a-z0-9][a-z0-9_-]*$`; локальный ключ — ≥ 2 сегментов через `.`, длина ≤ 255 байт, без `*`; полный ключ — ровно одно `:`, слева id панели, справа локальный ключ. Шаблон — локальный ключ, у которого **только последний** сегмент может быть `*` или `**`; ≥ 2 сегментов с учётом подстановки (значит, префикс ≥ 1 сегмента); голые `*`, `**`, `*` или `**` не в конце, `***`, пустые сегменты — ошибка. Сопоставление: точный шаблон — равенство строк; `p.*` покрывает ровно один сегмент после `p.`; `p.**` покрывает ≥ 1 сегментов после `p.`; `p.**` не покрывает `p`. Регистр не нормализуется: верхний регистр, пробелы, управляющие байты, не-ASCII — ошибка. Id панели и ключ роли — `^[a-z0-9][a-z0-9-]{0,63}$`. Нарушение ключа/шаблона → `InvalidPermissionKeyException`, панели → `InvalidPanelIdException`, роли → `InvalidRoleKeyException`; сообщение называет значение (через `json_encode`) и правило. Matcher не строит regex из входа: сравнение по массивам сегментов. Kernel не импортирует `Illuminate\`/`Carbon\`, не вызывает `app()/config()/now()`. Исключения — pure PHP (без Laravel), `code()` возвращает snake_case код из 05 §10. P14: тест `tests/Regression/P14Test.php` с именем, которое войдёт в spec, доказывает отказ голых `*`/`**` грамматикой; spec получает `**Status:** covered: tests/Regression/P14Test.php::<имя теста>` и строку под полями «Kernel-уровень закрыт P1.2 (грамматика); отказ значений `PermissionKey`/`PermissionPattern` — V02 в unit-тестах P1.1; сквозной сценарий ниже — acceptance V17/V22 пунктов P4.7/P5.2». Без внутренних кодов задач в docblock `src`. Запись `[Unreleased]` в `CHANGELOG.md`.
**Code Guidance:** Публичная форма (сигнатуры уточняются кодом, имена фиксированы): `PermissionGrammar::isSegment/isLocalKey/isPattern/isPanelId/isRoleKey(string): bool`, `assertLocalKey/assertPattern/assertPanelId/assertRoleKey(string): void`, `splitFull(string $full): array{0: string, 1: string}` (с проверкой обеих частей), константы `MAX_LOCAL_LENGTH = 255`, `WILDCARD_ONE = '*'`, `WILDCARD_DEEP = '**'`.
