## Validation strategy

Каждый implementation item: targeted `vendor/bin/pest <paths>`; `composer test`; `vendor/bin/pint --test`;
`vendor/bin/phpstan analyse --memory-limit=1G`; `php -d memory_limit=1G vendor/bin/pest --type-coverage --min=98`;
`php bin/api-manifest.php --check` после `composer api:manifest`; `vendor/bin/pest tests/Arch`; `git diff --check`. Arch-правило
пункта доказывается RED на временной копии в scratch. Регрессия probe — файл `tests/Regression/<Probe>Test.php` и строка `covered:`
в `tests/Regression/specs`. СУБД (D4, D14 п.6): `docker compose up -d --wait postgres mysql mariadb` (P4.8 ещё `redis`), затем
`DB_CONNECTION=<engine> php -d memory_limit=1G vendor/bin/pest --group=engines --fail-on-skipped`; Redis —
`composer test:redis`; недоступный сервис — `unavailable`, пункт не закрывается 🟢. Время в тестах фиксируется
(`Carbon::setTestNow`/`travelTo`), без `sleep` кроме барьеров процессов. Review-пункты read-only: `git status --porcelain -- packages tests bin`
пуст после review.
