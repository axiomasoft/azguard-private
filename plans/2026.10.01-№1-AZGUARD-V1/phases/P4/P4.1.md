**Implementation Rules:** `Authorizer::decide(Panel $panel, AccessRequest $request, ?ActorRef $actor = null): Decision`; actor по умолчанию — `ActorRef::of($subject->type(), $subject->id())`. Ошибки конфигурации/идентичности direct API выбрасываются: неизвестное статичное право → `UnknownPermissionException` (dynamic lookup — P4.17), субъект, которого панель не принимает, → `SubjectNotAcceptedException`, повтор `key()` двух restrictions панели → `DefinitionException`. Всё, что бросают хуки, источники, политики, условия, restrictions, — отказ с причиной и `Log::warning` (компонент, причина, класс исключения), наружу не выходит. `now` — один `DateTimeImmutable` UTC на проверку (`Carbon::now()` → immutable). Стадии строго по 09 §2: **Prepare** — `PanelCatalog::find(local)`, режим из `PermissionDefinition::$authority`, модель субъекта через `ModelSubjectResolver` (тип субъекта ↔ `Panel::subjectModels()`/morph alias; запись загружается `newQuery()->whereKey()->first()`, отсутствующая → `null`), `AccessScope` из запроса (по умолчанию `TenantRef::global()`/global context). **Boundary** — до P4.6 только строка none/none (D14 п.3): явный не-global tenant → `Deny(TenantMismatch)`, явный не-global context → `Deny(AssignmentScopeNotAccepted)`. **Before** — хуки в порядке регистрации, каждый `(AccessRequest, EvaluationContext): BeforeResult` через RuntimeInvoker D15 §2; `Deny` → `Deny(Hook, component)`; не-`BeforeResult` или исключение → `Deny(HookError)`; первый Deny/ошибка останавливает. **Authority/Policy** — ни один источник с `ProvidesGrants`/`ProvidesRoleGrants` не вызывается; `PolicyDecider` по привязке каталога: `true`/allow-`Response` → кандидат `Allow(Policy)`, `false`/`null`/deny-`Response` → `Deny(Policy)`, ошибка → `Deny(PolicyError)`; состояние — `CodeStateToken::of(panel, buildId, fingerprint)`. **Authority/Grants** — опрашиваются **все** источники с этими capabilities (`grants($subject, [$scope], $frame)`, `roleGrants(...)`), порядок не влияет (P12); исключение любого → `Deny(SourceError)` даже при уже найденном Allow; невалидный вклад (панель паттерна или RoleKey ≠ выбранная панель (до local lookup), scope не из запрошенных, не `Grant`/`RoleContribution`) → `Deny(SourceError)`; `RoleContribution` с ключом вне `PanelCatalog::roles()` — ноль прав и диагностика в трассе/логе, не ошибка. Квалификация одной contribution: `activeAt(now)` (`expiresAt <= now` истекла), затем все `GrantCondition` панели AND с кадром этой contribution (`role()` — экземпляр класса роли из контейнера, `grant()` — сама contribution); `false` → вклад отброшен, исключение → `Deny(ConditionError)`. Роль с `super_admin` квалифицирует любое Grants-право панели; иначе компилированные паттерны роли через `PatternMatcher::covers`; прямой `Grant` — своим паттерном. Нет квалифицированного вклада → `Deny(NotGranted)`. Есть привязка политики у права → veto: `false`/deny → `Deny(Policy)`, ошибка → `Deny(PolicyError)`, `true`/`null` → pass. Frame хранит qualifiedSuperAdmin witness; причина SuperAdmin при таком вкладе, иначе Granted. Eligibility/exemption не выводится из reason. **Restrictions** — в порядке регистрации; `appliesTo` false → пропуск; при qualifiedSuperAdmin witness в Grants mode и `exemptsSuperAdmin()` → пропуск; `deny` → `Deny(Restricted, component=key)`; исключение в `appliesTo`/`check` → `Deny(RestrictionError)`; restrictions проверяют любой кандидат, включая Policy и SuperAdmin. **After** — `(AccessRequest, EvaluationContext, Decision): void`, исключение → лог, решение не меняется. `EvaluationFrame` — immutable реализация `EvaluationContext`, копия на каждую contribution (`forContribution()`); `matchingGrants()` — квалифицированные прямые `Grant`, покрывающие право (пусто для PolicyOnly); `state()` — `CodeStateToken` (fenced источников ещё нет). Повторный вход в тот же кадр (панель, субъект, право, scope) из политики → `Deny(PolicyError)` с `RecursionDetectedException` в логе; другие scoped-проверки внутри политики разрешены. `Trace` пишет шаги только при `AccessRequest::isTraced()`. Компиляция панели проверяет списки: before/after — `Closure` или class-string invokable-класса; restrictions — объект или class-string `Restriction`; grantConditions — объект или class-string `GrantCondition`; иначе `DefinitionException` с происхождением записи; class-string разрешается контейнером на операцию, не при сборке. Arch allowlist D15 §7: sources используют публичные API/SPI/values, не реализации Authorization; coordinator вправе импортировать panel/catalog/storage implementations. Создаётся RuntimeInvoker::invoke(callable, array named inputs): mixed по D15 §2. Reserved input не заменяется новой моделью из DI. Contribution provenance берётся из реального source adapter, не self-reported source string; DB NotGrantable/removed/former roles — ноль authority.
