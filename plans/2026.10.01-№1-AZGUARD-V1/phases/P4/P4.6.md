**Implementation Rules:** Разрешение scope (09 §3): явный `inTenant`/`on:` запроса → иначе scope ресурса (`resourceScopes` резолвер по классу ресурса либо `ProvidesAccessScope`) → иначе текущий scope этой панели (`CurrentContext`). Явный/текущий tenant должен совпасть с владельцем ресурса (`Deny(TenantMismatch)`), выбранный context — с context ресурса (`Deny(AssignmentScopeMismatch)`); ресурс в tenant-панели без резолвера — `Deny(ResourceScopeMissing)`; tenant-панель без выбранного tenant — `Deny(TenantRequired)`, без fallback на глобальные права. `AssignmentScopeRef` проверяется `AssignmentScopeDefinition::resolve()` (null — `Deny(AssignmentScopeNotAccepted)`; исключение — `Deny(AssignmentScopeFilterError)`; вернувшийся ref/tenant не совпал с запросом — `Deny(AssignmentScopeMismatch)`); тип, которого нет в политике панели, — `Deny(AssignmentScopeNotAccepted)` (явный ref не игнорируется). Scopes для источников по таблице 09 §3: inherit — `[(T, global), (T, C)]`; isolated — `[(T, C)]` при C, `[(T, global)]` при global; required — при global `Deny(AssignmentScopeRequired)`, при C `[(T, global), (T, C)]`; none — `[(T, global)]`, C → `Deny(AssignmentScopeNotAccepted)`. Глобальная (`tenant = global`) ordinary выдача не включается в tenant T ни в одном режиме (P13). Членство: `required()` включает `requireMembership` по умолчанию, отсутствие адаптера — `DefinitionException` при сборке; не член — `Deny(Restricted, component=membership)`, исключение — `Deny(RestrictionError)`; членство проверяет активное членство, не наличие выдачи. Общие фильтры: один `EXISTS` по `query()->whereKey(id)` с группой фильтров на fresh Builder; `false` → `Deny(AssignmentScopeIneligible)`, ошибка запроса → `Deny(AssignmentScopeFilterError)`. Ролевые фильтры: контекстный вклад роли квалифицируется, только если тип контекста — один из `scopes()` роли и её binding-фильтры принимают контекст (`AssignmentScopeRuntime` с этим `BaseRole`, этой contribution, target user, actor, `now`, фаза Access); `scopeRequired()` роль с tenant-wide вкладом не квалифицируется; `false` удаляет только этот вклад. Фильтр меняет только свою группу `where`: после `apply()` builder проверяется на `from`/connection/joins/unions/limit/offset/orders/terminal-вызовы — неподдержанная форма → `DefinitionException` (без широкого fallback). Allow требует одного целого witness `(tenant, context, contribution, conditions)`. `WithinContext::run(Panel, AccessScope, Closure)` восстанавливает прежний scope в `finally`, включая исключение резолвера на входе.
