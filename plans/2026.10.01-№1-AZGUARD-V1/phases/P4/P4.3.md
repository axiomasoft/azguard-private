### P4.3 — Mode-aware policies, Decides, PolicyFor, GateSource::map

**Intent:** Довести политики до таблицы 09 §5: точная привязка через `#[Decides]`/`PolicyBinding`/`#[PolicyFor]`, нативный DI субъекта и ресурса (включая class-аргумент без экземпляра), нативный `before` политики, сохранение `Response` (status/message/code) в `Decision`; `GateSource::map()` как политика из существующей ability Laravel без рекурсии; статичный O(1) индекс «модель + слово ability → право панели» для Gate.
**Why:** RAG:— 09 §1 (одно слово + model, class argument, owned vs foreign), §5 (таблица authority, GateSource, native before), §16 (binding/Decides обязательны); 05 §7 (атрибуты ресурсов и политик); 19 §2 (`ClientPolicy`, Response, recursion), §9; D26, D53, D65, D83, D84 досье; 20 F04; V67, V68, V80, V93, V102; R21, R22, R61–R64; D14 плана п.3 (вызов политики: ядро P4.1, расширение здесь; поля отказа `Decision`).
**Scope Included:** `PolicyDecider`: аргументы метода — модель субъекта, затем ресурс из запроса либо, если ресурса нет, class-string `resourceModel` определения права (`viewAny`/`create`); обязательный параметр без значения — отказ без вызова (`Deny(PolicyError)`, причина в логе); нативный `before($user, $ability)` политики вызывается первым, его не-`null` результат — результат политики, интерпретируемый по режиму; `Response` нормализуется через `allowed()`, `message()`, `status()`, `code()`. `Kernel\Decision\Decision` получает nullable `message`, `status`, `code` (скаляры; заполняются из `Response` политики при Deny(Policy) и Allow(Policy)). `@api` `Sources\Gate\GateSource implements ProvidesPolicies, DescribesSchema` с `make()`, `map(string|UnitEnum $permission, string $ability)`; при сборке: право существует в каталоге, ability определена (`Gate::has`), имя ability не является полным/локальным именем права AzGuard (иначе рекурсия) — нарушение → `DefinitionException`. Индекс ability в `PanelCatalog`: для enum с `#[Resource(model:)]` — `[класс модели][последний сегмент локального имени]` → локальный ключ (`view_any` ↔ `viewAny` через `Str::snake`); две записи на одну пару — помечена неоднозначной.

**Implementation Rules:** Режим определяется только `PermissionDefinition::$authority`, не наличием политики или источника. PolicyOnly: привязка обязательна (компиляция P2.5); `true`/allow → `Allow(Policy)`; `false`/`null`/deny → `Deny(Policy)`; назначения не читаются, `matchingGrants()` пуст. RequiresGrant: привязка необязательна; её отсутствие — pass; `true`/`null` — pass только при квалифицированном вкладе; `false`/deny → `Deny(Policy)` даже при superadmin. `ConsultsGrants`/policy OR grants нет. Метод выбирается только атрибутом `#[Decides(case)]` (`PanelCatalog::bindingMethod`), имя метода свободно; вызов — `Container::call([$policy, $method], …)` с позиционными субъектом и ресурсом, остальное — DI. Политика, бросившая исключение, или вернувшая не bool/null/`Response`, — `Deny(PolicyError)`. `GateSource` вызывает определение ability напрямую (замыкание `Gate::abilities()` или метод политики, найденный `Gate::getPolicyFor`), **не** `Gate::check/inspect`: глобальные `Gate::before` (включая будущий `GateBridge`) не вызываются повторно. `GateSource` — `ProvidesPolicies`: его результат интерпретируется по режиму права как любая политика; одно право — одна политика (`DuplicatePolicyBindingException` при второй привязке). Индекс ability строится при компиляции каталога и попадает в снимок `catalog:cache`; ключи — FQCN модели и слово ability; поиск O(1). Поля отказа `Decision` не влияют на `allowed()`; `Decision::admits` не меняется.
**Code Guidance:** V80 — таблица 09 §5 построчно: `Refund` (RequiresGrant) — назначение AND `WorkingHoursPolicy` veto; `ViewOwn` (PolicyOnly) — владелец заказа без единой выдачи, spy-источник не вызван; удаление `#[Decides]` у объявленного метода — `DefinitionException` при сборке; переименование метода с сохранением атрибута — та же привязка. V93 — `Response::deny('Closed', 'orders.closed')->withStatus(404)` → `Decision` с `status=404`, `message`, `code`; RequiresGrant `true` без выдачи → `NotGranted`; token cap — `TokenAbilitiesRestriction` AND с разрешением политики. V67 — DI: метод `update(User $user, Order $order, Clock $clock)` получает сервис из контейнера; `viewAny(User $user)` и `create(User $user)` вызываются с class-аргументом; обязательный `Order $order` без ресурса — отказ без вызова. Нативный `before` политики, вернувший `true` в RequiresGrant без выдачи — `NotGranted`. `GateSource`: ability `beta-access` через `Gate::define`, отображение на `BetaPermission::Access`; дополнительный `Gate::before(fn () => true)` не меняет результат GateSource; map на имя права AzGuard — `DefinitionException`.
