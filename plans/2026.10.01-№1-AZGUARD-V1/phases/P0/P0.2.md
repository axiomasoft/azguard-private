### P0.2 — Probes 0.3 → спецификации регрессионных тестов с owning items

**Intent:** Превратить 19 исполняемых probes 0.3 в спецификации регрессий нового API с обратным ожиданием и owning item плана, чтобы ни один дефект не потерялся при перестройке; соответствие держит meta-тест.
**Why:** RAG:— `evidence/README.md` «Карта probes → находки» (P01a–P14, 19 tests) и колонка Probe в `14-verification.md`; правило 13 §0 п.2: пункт без регрессионного теста своего probe не закрыт.
**Scope Included:** `tests/Regression/README.md` (назначение, формат, правило закрытия); по одному файлу `tests/Regression/specs/<probe-id>.md` для P01a, P01b, P01c, P02, P03, P04a, P04b, P04c, P05, P06, P06b, P07, P08, P09, P10, P10b, P11, P13, P14 с полями: `Probe`, `Finding` (N##/C##), `Owning item` (`PLAN2.Pn.m`), `Scenarios` (V-ids), `Defect in 0.3` (что доказывал probe, со ссылкой на тест-метод в `audits/.../evidence/probes/*.php`), `Required behavior` (сценарий на целевом API досье с конкретными вызовами и ожиданием), `Status` (`pending` | `covered: <path>::<test>`). Meta-тест `tests/Regression/RegressionSpecsTest.php`: все 19 файлов есть; поля заполнены; owning item совпадает с ожидаемым для этого probe (таблица в тесте, повторяет Implementation Rules) и имеет форму `PLAN2.Pn.m`; V-ids имеют форму `V\d{2,3}` и встречаются в `audits/2026-09-29-audit/opus/14-verification.md`; для `covered:` путь и имя теста существуют.
**Scope Excluded:** сами регрессионные тесты на новом API (их пишут owning items P1–P5); изменения probes в `audits/`.
**Inputs:** `plan.md` · `phases/P0/P0.md` · `tests/Pest.php` (каркас P0.5) · `audits/2026-09-29-audit/opus/evidence/README.md` · `audits/2026-09-29-audit/opus/14-verification.md` · `audits/2026-09-29-audit/opus/13-workstreams.md`.
**Files:** `tests/Regression/README.md` · `tests/Regression/specs/*.md` · `tests/Regression/RegressionSpecsTest.php`.
**Required Reads:** 1) `audits/2026-09-29-audit/opus/evidence/README.md` 2) `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditProbesTest.php` 3) `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditContextProbesTest.php` 4) `audits/2026-09-29-audit/opus/14-verification.md` 5) `audits/2026-09-29-audit/opus/13-workstreams.md` 6) `audits/2026-09-29-audit/opus/01-review.md` §4 (только находки, на которые ссылаются probes) 7) `audits/2026-09-29-audit/opus/05-php-api.md` §0–§1 (форма целевых вызовов).
