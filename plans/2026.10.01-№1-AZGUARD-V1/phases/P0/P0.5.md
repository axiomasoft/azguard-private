### P0.5 — Legacy freeze и каркас пакетов 1.0 с зелёными гейтами

**Intent:** Освободить namespace `AzGuard\` для 1.0: заморозить код и тесты 0.3 в `legacy/0.3/` и поднять пустые пакеты 1.0 с рабочей Testbench/Pest-инфраструктурой и зелёными гейтами D4.
**Why:** RAG:— целевые классы 1.0 (`Panels\Panel`, `Panels\PanelResolver`, `Roles\BaseRole`, …) совпадают по FQCN с классами 0.3 в `packages/core/src`; сосуществование в автозагрузке невозможно (D2). Все последующие фазы требуют единых гейтов D4.
**Scope Included:** `git mv packages/core packages/context packages/filament tests` → `legacy/0.3/{packages,tests}`; `git mv` корневых отчётов 0.3 (`ARCHITECT_REVIEW.md`, `IMPROVEMENT_PLAN.md`, `INTEGRATION_FEEDBACK.md`, `REMAINDER_REPORT.md`, `phpstan-baseline.neon`) → `legacy/0.3/`; `legacy/0.3/README.md` (что это, источник HEAD `f6d33cc`, удаляется в PLAN2.P6.9, не автозагружается). Новые `packages/core/composer.json` (`axiomasoft/azguard`, `AzGuard\` → `src/`, require `php ^8.3` + `illuminate/{contracts,support,database,console,http,routing,queue,filesystem}` `^11.0|^12.0|^13.0`, provider `AzGuard\AzGuardServiceProvider`) и `packages/filament/composer.json` (`axiomasoft/azguard-filament`, `AzGuard\Filament\` → `src/`, require `axiomasoft/azguard: self.version`, `filament/filament ^5.0`, provider `AzGuard\Filament\AzGuardFilamentServiceProvider`). Пустые `final` провайдеры с `register()`/`boot()`. Корневой `composer.json`: require двух новых пакетов, path-repo `packages/*` с версиями `1.0.0` для локальной разработки, autoload-dev `AzGuard\Tests\` → `tests/`, scripts без `mutate:context` и без перечисления удалённых Redis-файлов (`test:redis` → `pest --group=redis`). Новая `tests/` (`Pest.php`, `TestCase.php` на Testbench с SQLite/pgsql/mysql connection по env, `Arch/BaselineArchTest.php`, `Unit/`, `Feature/ServiceProviderTest.php`, `Regression/`, `Fixtures/`). `phpunit.xml` (suites Arch/Unit/Feature/Regression, source = `packages/*/src`), `phpstan.neon` (paths `packages/core/src`, `packages/filament/src`, level 8, без baseline, exclude `legacy`), `rector.php` (новые paths), Pint с exclude `legacy`. CI: `tests.yml`, `static-analysis.yml`, `mutation.yml`, `code-style.yml`, `bin/mutation-gate.sh`, `bin/coverage-gate.sh` — новые пути, без `context`; Redis-job выключен `if: false` с комментарием «включает PLAN2.P4.8». `DEVELOPMENT.md` — раздел «Состояние 1.0» с путями и D2. `CHANGELOG.md` `[Unreleased]`.
**Scope Excluded:** классы ядра сверх двух провайдеров; изменения внутри `legacy/` кроме README; composer homepage/support/branch-alias/release/split (P0.4); consumer fixture (P0.3); docs site.

**Implementation Rules:** Перемещать только `git mv` одним коммитом, без правок содержимого legacy — история 0.3 читается через `git log --follow`. Ни один autoload/scan (composer, Pest, PHPStan, Rector, Pint, coverage source) не включает `legacy/`. Новые PHP-файлы: `declare(strict_types=1)`, `final`, без docblock-ссылок на коды задач. PHPStan level 8 без baseline: каркас должен проходить чисто; повышение/понижение уровня — только через новый D#. `failOnEmptyTestSuite` сохраняется: каждая suite содержит минимум один содержательный тест (Arch: strict_types + отсутствие `dd/dump/ray`; Feature: оба провайдера регистрируются в Testbench, filament-провайдер — при установленном Filament). CI-матрица PHP×Laravel×stability не сокращается. `composer update` выполняется только для синхронизации lock с новыми path-пакетами; версии сторонних пакетов не поднимать сверх необходимого (`composer update axiomasoft/* --with-dependencies` или эквивалент). Чужой неотслеживаемый `.swissknife/` не трогать.
**Code Guidance:** Testbench `TestCase` повторяет 0.3-приём `databaseConnectionConfig()` по `DB_CONNECTION` (sqlite `:memory:` по умолчанию; pgsql/mysql — env `PGSQL_*`/`MYSQL_*` с `azguard_test`), без `az-guard.*` конфига. Pest: `uses(TestCase::class)->in('Unit', 'Feature', 'Regression')`; arch-набор в `tests/Arch/`, позже P1.4 добавит правила зон. Filament-провайдер в 1.0-каркасе пустой: регистрация плагина — P7.1.
**Validation:** 1) `composer validate --strict` и `composer validate --strict packages/core/composer.json packages/filament/composer.json`; 2) `composer dump-autoload` и `composer show axiomasoft/azguard axiomasoft/azguard-filament` — path-пакеты установлены; 3) `composer test` — GREEN, ≥1 тест в каждой suite; 4) `vendor/bin/pint --test`; 5) `vendor/bin/phpstan analyse --memory-limit=1G` — 0 ошибок; 6) `vendor/bin/rector process --dry-run` — без изменений; 7) `vendor/bin/pest --type-coverage --min=98`; 8) `git grep -nE 'AzGuard\\\\Context|packages/context' -- ':!legacy' ':!audits' ':!plans' ':!CHANGELOG.md'` — пусто; 9) `php -r` автозагрузка `AzGuard\Panels\Panel` не находит класс (legacy вне autoload); 10) `git diff --check`.
**Deliverables:** `legacy/0.3/` с README; каркас двух пакетов 1.0; новая `tests/` с зелёными suites; tool-конфиги и CI на новых путях; запись в `CHANGELOG.md`; execution evidence в `findings/P0-execution.md`.
