`lib/task/plan_evidence.py::material_product_paths()` сохраняет brace/glob
выражения из Files буквально. Потребители
`lib/task/review_packet.py::_members()` и
`lib/task/task_contract.py::current_validation_context()` не раскрывают их.

байтов существующих файлов. Изменение реального файла может не изменить такой
digest; один validation tree недостаточен для доказательства freshness.

Текущая приёмка: передать конкретные owning changed/new/deleted файлы через
review-packet --path, сохранить полный concrete candidate inventory и связать
каждый реальный validation запуск с этим кандидатом. Не считать brace/glob
placeholder доказательством покрытия.

Исправление принадлежит отдельному bounded пункту SKM: единая конкретизация
declared product paths для review snapshot и validation context, с проверкой
новых/удалённых файлов и freshness. В AZGUARD runtime не исправлялся.

Дополнительные наблюдения окружения: команда `python` отсутствует (использован

## Immutable closure dependencies: подтверждённый блокер P4.4

Canonical immutable predecessor verifier (introduced in SKM 2ea11457) reconstructs
reviewed inputs only from the first closure commit. Ignored vendor files are not
present there, despite their original reviewed hashes being unchanged.
P4.3 baseline 5541265 has exactly two such missing Laravel Gate/Response inputs;
this is the thirteenth foreign baseline lint error, not a new P4.4 mutation.

P4.4 GREEN includes three ignored Laravel DB supporting files and ignored
composer.lock as a read-only dependency in snapshot.product. Their bytes still
match the authenticated original snapshot. Committing without archived witnesses
would make P4.4 immutable closure proof fail. Current live review/pre_final/finalize
and terminal build pass; this does not prove postcommit immutable acceptance.

Owning repair is isolated from concurrent SKM work: additive source witnesses bound
to the original receipt/manifest/candidate, archived only after original hash/mode
verification. Original review artifacts and completed verdict must remain unchanged.
P4.3 stays visible as a foreign baseline defect; no historical receipt is repaired
or rewritten for the current solo request.
