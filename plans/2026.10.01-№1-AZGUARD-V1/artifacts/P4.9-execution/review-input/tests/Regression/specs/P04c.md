# P04c — Две выдачи в разных проектах объединяются как OR

**Probe:** P04c
**Finding:** N04
**Owning item:** PLAN2.P4.12
**Scenarios:** V32
**Defect in 0.3:** Две scoped-выдачи одной роли в проектах `a` и `b` складывались через AND и скрывали оба проекта: `count()` давал 0. Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditProbesTest.php`, `it('P04c: two scoped assignments compose with AND and hide both projects')`.
**Required behavior:** Роль в двух проектах делает видимыми оба; tenant-wide право открывает все строки выбранного tenant при точных ограничениях и предикатах политики.
**Status:** pending

## Сценарий на целевом API

```php
$user->guard('seller')->grantRole('project-viewer', on: $a);
$user->guard('seller')->grantRole('project-viewer', on: $b);
$c = Project::factory()->create();   // без выдачи

$visible = AzGuard::panel('seller')->visibility()->visibleTo(Project::query(), subject: $user, permission: ProjectPermission::View);

expect($visible->pluck('id')->all())->toEqualCanonicalizing([$a->id, $b->id]);
```
