# P03 — Подменённые хуки и источники видят все входы одинаково

**Probe:** P03
**Finding:** N03
**Owning item:** PLAN2.P4.3
**Scenarios:** V30
**Defect in 0.3:** Resolver из `az-guard.resolver` отказывал в `hasPermission`, но `Gate::allows` по тому же праву возвращал true. Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditProbesTest.php`, `it('P03: a restrictive az-guard.resolver is honoured by hasPermission() but not by the Gate')`.
**Required behavior:** Подменённый хук или источник, запрещающий право, виден одинаково через трейт, фасад, Gate, `@can`, `azguard.can`, `decideMany` и `azguard:explain`; Gate не обходит запрет.
**Status:** pending

## Сценарий на целевом API

```php
AzGuard::configurePanel('admin', fn (PanelBuilder $panel) => $panel->restrictions([DenyEverything::class]));
$user->guard('admin')->grantRole('manager');

$answers = [
    $user->hasPermission(OrderPermission::View, guard: 'admin'),
    AzGuard::check($user, OrderPermission::View, guard: 'admin'),
    Gate::forUser($user)->allows('admin:orders.view'),
    AzGuard::panel('admin')->decideMany([...])->allowed(OrderPermission::View),
];
expect(array_unique($answers))->toBe([false]);
```
