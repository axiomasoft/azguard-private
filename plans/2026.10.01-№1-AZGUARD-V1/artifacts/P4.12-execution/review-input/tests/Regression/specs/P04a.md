# P04a — visibleTo без субъекта возвращает пусто

**Probe:** P04a
**Finding:** N04
**Owning item:** PLAN2.P4.12
**Scenarios:** V31
**Defect in 0.3:** Без `Auth::user()` (очередь, консоль, публичный маршрут) запрос scoped-модели не фильтровался: `Project::query()->count()` видел все строки. Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditProbesTest.php`, `it('P04a: without an authenticated user the scoped model query is unfiltered')`.
**Required behavior:** Auth глобально не читается; `visibleTo` без субъекта возвращает пусто. Форма вызова `visibleTo` фиксируется в P4.12, смысл задаёт V31.
**Status:** covered: tests/Regression/P04aTest.php::P04a returns no rows for an explicit null subject without reading Auth

## Сценарий на целевом API

```php
// форма вызова уточняется в P4.12; субъект передаётся явно
$visible = AzGuard::panel('seller')->visibility()->visibleTo(Project::query(), subject: null, permission: ProjectPermission::View);

expect($visible->count())->toBe(0);   // без субъекта — пусто, а не все строки
```
