## Scope Included

Ввести panel-qualified persisted name для code roles, точный class lookup,
controlled rename существующих строк с сохранением ID/assignments и diagnostics stale/invalid classes.

Разделить создание panel и добавление domain; actor/model из явных options/config;
безопасная регистрация без перезаписи чужого PHP.

## Scope Excluded

Глобальные table/class renames и обязательная class_name uniqueness без P6 migration proof;
новый PHP parser dependency; смена CLI namespace; silent DB-only adoption;
автоматическая миграция consumer string names.

## Acceptance

Два AdminRole в разных панелях получают разные persisted names и row IDs;
повторный sync сохраняет assignments. Class lookup точен, строковый lookup —
по точному persisted name, DB-only role с null class_name работает, level сохраняется.
Collision/stale/invalid definition даёт actionable error, а не пустое право.
Добавление domain не требует force-overwrite; generated policy/enum/provider
проходят smoke check с явными model/actor FQCN.

controlled rename без потери pivot rows; ошибочная definition fail-closed.

panel/path; повторный запуск и существующий domain сохраняют файлы; JSON doctor;
PHP lint сгенерированных файлов. SQLite `:memory:` и изолированные filesystem paths.

полную красную suite как отдельную обязательную фазу.
