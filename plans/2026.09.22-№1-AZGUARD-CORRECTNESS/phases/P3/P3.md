## Scope Included

Relations, helpers, builders, scoped-role reads и CLI используют опубликованные Role/Scope/DirectGrant/RolePermission subclasses, их table/connection и model behavior.

Database role JOIN стартует из configured RolePermission Eloquent builder; Resources, Create/Edit pages, filters, relation managers и doctor разрешают те же модели. Invalid class/table/connection config даёт понятную диагностику.

## Scope Excluded

Новый ModelRegistry/repository layer; замена базовых model type-hints interfaces; новая context model configurability; arbitrary non-subclass ORM; межмодельные/split-connection JOIN и transaction; применение global scopes к raw pivot table.

## Acceptance

Каждая из четырёх config models заменяется valid subclass с наблюдаемым table/event/scope behavior; официальные read/write/UI пути не инстанцируют default class. Type-hints базовых models допустимы.

Все AzGuard persistence models, pivots и permission-state revision используют одну effective connection; mismatch отклоняется до mutation. Eloquent global scope применяется к модели, из builder которой начат query; raw pivot JOIN не получает invented model semantics.
