**Implementation Rules:** Add base `down()` in FK-safe reverse order; do not claim rollback of 000004 with live null `scope_class`. For `model_has_roles`, create a connection-local staging relation with exact distinct assignment columns, verify staged/source cardinality invariants, then replace rows inside one transaction; an insert fault rolls back to the original rows. For `model_has_scopes`, stage keep IDs (`MIN(id)` per full nullable identity) and delete only non-kept IDs transactionally. Build staging data in SQL; PHP may iterate bounded metadata/ID chunks but must not materialize the table.
