## Scope Included

Восстановить fresh rollback contract; разделить исправленный fresh path и новую
forward-only upgrade migration. Dedupe выполняется на стороне DB с bounded PHP memory,
проверкой staged rows и транзакционной заменой данных; live/concurrent migration не обещается.

Driver-aware null-safe uniqueness без sentinel collision, exact `class_name` uniqueness,
quoted/configurable names, integer/UUID/ULID/context string identity; MariaDB — отдельный вердикт.
Для MySQL D14 ограничивает поддержку >=8.0.13, non-MariaDB, InnoDB 16-KiB, DYNAMIC-or-COMPRESSED;
fresh 000003 задаёт `panel_id` 128, deployed 000006 проверяет данные и capability до DDL.

## Scope Excluded

Live migrations, универсальный schema registry, переименование таблиц/колонок ради терминологии, обещание MariaDB без отдельного прогона.

## Acceptance

Fresh/up/down и recorded-legacy upgrade fixtures проходят на SQLite, PostgreSQL и
заявленном профиле MySQL; более узкий key budget и deployed panel ID >128 получают
явный fail-before-DDL без потери rows/legacy index.
Dedupe не оставляет пустую pivot table после insert/index failure; peak PHP memory и
lock duration зафиксированы на одном bounded fixture без формального performance gate.
Nullable uniqueness учитывает полную tuple и не сводит real zero/empty/UUID к `NULL`;
неукороченные values, custom/schema-qualified table names и PHPDoc совпадают с runtime.

## Validation strategy

P6.1: Fresh/up/down/up и pre-000005 upgrade с duplicates/bounded fixture; injected insert/index failure; потеря assignments исключена, а PHP не материализует всю pivot table.

P6.2: Legacy-index → new-index upgrade и fresh parity; overlength deployed data/capability preflight,
actual MySQL 16-KiB DDL with int/ULID/UUID, composite collisions, zero/empty/all-zero UUID,
values differing after char 191, custom/schema-qualified names; SQLite/PostgreSQL/MySQL.
MariaDB support только после actual run.

Конкретные test files/команды и expected outcomes закреплены в item Validation.
Reproduction и исправление выполняются в одном owning item; не коммитить
полную красную suite как отдельную обязательную фазу.
