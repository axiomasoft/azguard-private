# 07 — P4.12: portable explicit names for configurable morph indexes

> Слой 2. Синтез по
> `findings/P4.10-uuid-morph-index-name-2026-07-22.md` и P4 portability canon.

## Решение

Создать P4.12, а не re-open закрытый P4.8. P4.8 уже доставил и доказал remediation migration
000005; новый дефект находится в общем production-helper `MorphColumns`, от которого зависит
начальная migration 000000. Отдельное file ownership не переписывает исторические Completion
Notes P4.8 и делает следующий writer's scope однозначным.

P4.12 передаёт explicit short deterministic names в Laravel morph helpers. Имя обязано
содержать короткий stable fingerprint actual Blueprint table name и morph name: одно и то же
имя (`model_morph_idx`) на разных production tables недопустимо для PostgreSQL schema, а
Laravel-generated имя из полного configurable table name недопустимо для MySQL. Нельзя
сокращать table fixture: она является regression proof именно для длинного configurable table
name. RAG:— (repo-grounded: findings/P4.10-uuid-morph-index-name-2026-07-22.md;
packages/core/src/Database/Schema/MorphColumns.php:18-66).

## Границы

- `MorphColumns::add()` остаётся единственным production API и продолжает создавать те же
  columns/indexes; меняется только DDL identifier.
- P4.12 не меняет migration 000005, RBAC semantics, config keys, public `@api`, snapshot или
  CI workflow.
- P4.10 владеет только последующим full-lane proof, timeout 900 and CI/docs; 900 не должен
  попасть в P4.12 как substitute for a passing targeted proof.

SemVer: no-change. Это repair installability already promised by the configurable morph-key
contract; public PHP surface and stored data semantics не меняются. Если implementation
требует изменить public signature/config or API snapshot, P4.12 останавливается с §10 и новым
D# вместо silent scope expansion. RAG:— (repo-grounded: root/semver-policy.md §1–4;
tests/Fixtures/api-surface.snapshot.php; findings/P4.10-uuid-morph-index-name-2026-07-22.md).
