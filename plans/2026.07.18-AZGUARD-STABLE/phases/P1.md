**Status:** 🟠 Done with deviations
**Intent:** Устранить тихую потерю изоляции данных: `bootHasScopedRoles` выходит при

`Auth::login()` читает scoped-модели БЕЗ фильтра. Убрать SAPI-bypass; активацию scope

**Why:** Единственный Blocker аудита (REGISTER C-01, ось C C-C1). Молчаливая утечка
данных вне HTTP — прямое нарушение цели «tenant-isolation». RAG:— (repo-grounded:
