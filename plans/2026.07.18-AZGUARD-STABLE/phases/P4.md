### P4.7 — Collation-hardening RBAC-ключей (MySQL first-class, D24)

**Status:** ⬜ Not started
**Intent:** Driver-conditional binary/`utf8mb4_bin` collation на ключевые RBAC-строковые колонки
(`panel_id`, `permission_key`, `model_type`/морф-типы, `scope_class`, `context_type`/`context_id`)
— ТОЛЬКО для MySQL/MariaDB (PG/SQLite уже case-sensitive); тест case-sensitivity доказывает фикс
на MySQL-джобе P4.2.
**Why:** recon-db-portability §3/§7 — MySQL дефолт `utf8mb4_*_ci` case-INSENSITIVE → `panel_id`='App'
и 'app' СХЛОПЫВАЮТСЯ; unique `(role_id, permission_key, panel_id)` становится CI и отвергает
«разные» по регистру ключи как дубль; `model_type` (FQCN, case-sensitive в PHP-матчинге) матчится
нестрого = security-корректность-баг; owner D23 «MySQL first-class» + D10 fail-closed (регистр
РАЗЛИЧАЕТ ключи, как PHP `preg_match` без `i`). RAG:— (repo-grounded: findings/recon-db-portability-2026-07-18.md §3/§7;
WildcardPermissionMatcher.php:23; core migration 000002; context migration 000010).
**Scope Included:** правка core+context миграций (edit-in-place — git-тегов нет, свежие инсталы,
recon §CI «без git-тегов») — driver-conditional `->collation('utf8mb4_bin')` ключевым строковым
колонкам когда `getDriverName()` ∈ {mysql, mariadb}; тест `CollationCaseSensitivityTest` — вставка
ключей, различающихся ТОЛЬКО регистром, НЕ схлопывается (различимы), unique их не отвергает как
дубль; на sqlite/PG тот же тест зелён нативно; MySQL-джоб P4.2 становится доказательством.
**Scope Excluded:** input-канонизация как ЗАМЕНА schema-collation (выбран schema-level binary —
структурнее и fail-closed; канонизация полагается на каждый write-путь — НЕ строим); PG/SQLite
ветки (уже case-sensitive — не трогать); правка публичного PHP-API (миграции не @api, снапшот
P3 не задет); правка матчеров/резолверов (они уже case-sensitive в PHP — recon §3).
**Inputs:** findings/recon-db-portability-2026-07-18.md §1/§3/§7; core migration 000002
(role_permissions/direct_grants); context migration 000010 (context_roles); MorphColumns.php

**Files:** `packages/core/database/migrations/*000002*.php`, `packages/context/database/migrations/*000010*.php`,
