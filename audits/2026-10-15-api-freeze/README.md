# AzGuard: аудит перед окончательной фиксацией API

Дата: **15 октября 2026**. Проверенный commit: `2ce692f74c210e81426e9367303701516b1cc3f0`.

**Вывод: архитектуру стоит сохранить, но текущий API и его гарантию совместимости пока рано окончательно фиксировать.** Есть воспроизводимые расхождения авторизации, дефекты границы записи и незавершённые контракты расширений. Большой штатный набор тестов проходит, поэтому исправлениям нужны новые проверки именно найденных сценариев.

Начать с [основного отчёта](REPORT.md). Для реализации следующей моделью — [очерёдность и критерии готовности](IMPLEMENTATION.md). Полные доказательства и ограничения приведены в приложениях:

| Документ | Содержание |
|---|---|
| [Авторизация](parts/authorization.md) | Scalar, batch, SQL, переданный subject, directories и источники |
| [Запись, расширения, Audit](parts/storage-extensions.md) | Единственный writer, участники транзакции, физическая БД, retention, custom fields |
| [Filament и Laravel](parts/filament-laravel.md) | Операции, widgets, Livewire, запросы интерфейса и жизненный цикл |
| [План и поставка](parts/plan-delivery.md) | API/SPI, compatibility comparator, история квалификации, CI, документация |
| [Проверки](VALIDATION.md) | Фактические команды, результаты, исправленные проблемы окружения и границы проверки |
| [Схемы](diagrams/README.md) | Владение компонентами, согласование решений, транзакция и закрытие freeze |
| [Доказательства](evidence/README.md) | Запуск воспроизведений, логи и машинные результаты |

Production-код, штатные тесты, manifests и закрытый план при аудите не изменялись. В локальной установке обновлены игнорируемые Composer metadata двух path-пакетов, чтобы автозагрузчик видел существующие модули. Вся содержательная работа сохранена в этой папке. Документы — результат аудита и предложение следующей работы; новые формы API, явно отмеченные как предложения, ещё не реализованы.
