## 4. Процессы

- **CI (12 workflow).** Покрытие хорошее: матрица PHP×Laravel, БД-матрица, coverage, mutation, CodeQL
  (actions), zizmor, split, release с preflight. Исправлено: `npm install` → `npm ci` в docs; устаревшие
  комментарии (level 6, ссылка на P4.5).
- **Composer-скрипты.** Удалены дубли `mutate:all`/`mutate:diff` (второй обещал несуществующий diff-режим) и
  `test:coverage` (без проверки драйвера, OOM). Добавлен `bench`.
- **Релиз.** Заметки релиза собирает git-cliff из сообщений коммитов. Коммиты пишутся по-русски, поэтому
  заметки релиза 1.0 будут смешанными. **Нужно обсудить:** брать тело релиза из раздела CHANGELOG (он уже
  проверяется preflight), а git-cliff оставить для черновика.
- **Makefile** — только docker up/down/logs/ps. Достаточно; дублировать composer-скрипты не нужно.
- **roadmap/azguard-evolution.md** описывает идеи эпохи 0.3 (level, class-as-identity). **Нужно обсудить:**
  обновить под 1.0 или перенести в архив плана.
- **`composer check` молча пропускает coverage и mutation** без драйвера. CI их всё равно выполняет, поэтому
  оставлено. **Нужно обсудить:** падать локально без драйвера.

## 8. Предложения

1. **Мемо субъекта на запрос.** Сейчас субъект перечитывается на каждой проверке: это N+1 на списках и треть
   времени тёплой проверки. Тесты закрепляют живое перечитывание, поэтому попытка мемо откатана. **Нужно
   обсудить:** опция `consistency(subjectReads: Request|Check)` с `Check` по умолчанию.
2. **Мемо `PanelSources` на запрос.** ~11% лёгкой проверки, без смены поведения (источники stateless по
   контракту). Низкий риск.
3. **Фасад видимости.** `AzGuard::panel('admin')->visibility()->visibleTo($admin->definition(), ...)` —
   громоздко. Предлагается `$user->visible(Post::query(), PostPermission::View)`.
4. **Понятная ошибка видимости.** Источник без `FiltersQueries` даёт `source_error`, хотя это неподдерживаемая
   конфигурация. Нужен отдельный код и проверка doctor.
5. **Модель области в `on:` попадает в политику как `$resource`** — неочевидно. Задокументировано; **нужно
   обсудить** отдельный параметр.
6. **Doctor-проверки Filament.** Проверять trait-ы и guard-панель до первого запроса.
7. **`FolderSource` и автоматические роли с видимостью.** Не поддержано — ошибка настройки. Описать или
   поддержать.
8. **Stub политики** генерирует `true` для `RequiresGrant` — верно, но без подсказки о вето.
9. **`azguard:filament:generate`** создаёт CRUD-enum для read-only `RoleResource`. Лишние права.
10. **Иерархия исключений.** Много узких классов. Оценить объединение по кодам перед фиксацией API 1.0.
11. **147 МБ артефактов плана в публичном репо** (логи, локальные пути, источник утечки ключа). Перенести в
    приватное хранилище или release-артефакт. Удаление из дерева не очищает историю.
12. **`composer.lock`** не коммитится (библиотека). CI использует prefer-lowest/stable. Оставить так.
13. **PHPStan level 9** — см. раздел 7.
