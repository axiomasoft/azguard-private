# Severity guide

- **Blocker**: demonstrated acceptance/safety violation preventing acceptance.
- **Major**: material defect requiring repair or explicit accepted deferral.
- **Minor**: real bounded defect that does not block acceptance.
- **Nit**: optional style/preference; never blocks.

Labels (`issue`, `suggestion`, `question`, `nitpick`) describe intent independently. Every
finding includes location, failure scenario and evidence; nonconformance cites an adopted
requirement. Report uncertainty separately. Unadopted advice cannot create a gate.
