# Код после сужения матрицы

Публичные типы, ключи конфигурации и SQL не менялись. `DatabaseSource` (1400 строк) и остальные крупные публичные классы не разрезаны: вынос методов в новые публичные типы ломает манифест, а внутренний перенос без смены поведения — отдельный дифф без выигрыша по времени запроса.

## Что изменилось

`ClassTraits` запоминает `class_uses_recursive()` на имя класса на время процесса. Трейты загруженного класса не меняются, в том числе под Octane. Раньше обход повторялся на каждом Livewire `mount`/`hydrate` виджета, на каждой проверке ресурса Filament и при разборе soft-deletes записи. Шесть вызовов сведены к одному помощнику.

`GrantEditor` один раз строит карты ролей, прав и моделей субъектов. Раньше каждая строка таблицы заново проходила списки схемы. Каталоги субъектов и типов контекста тоже держатся на редакторе страницы: `directories()` больше не собирается заново на каждую строку. Первое совпадение ключа по-прежнему побеждает, как линейный цикл.

`PermissionSetCache` читает array-store через `all(false)`. Это те же байты, что лежали в приватном `storage`, без `unserialize`. Тест `does not deserialize a forged outer value in a serialized array store` зелёный: 8 утверждений, поддельный объект не просыпается.

Редакторы грантов: `RoleGrantResourceTest` и `PermissionGrantResourceTest` зелёные вместе с остальными не-Redis тестами файла конвертов (42 passed). Один тест того файла требует Redis и локально не запускался.

## Чего это не делает

Число строк почти не изменилось. Дублирования между MySQL и MariaDB нет в этом срезе. Дорогие тесты паритета и вложенные процессы `CapabilityMatrixCoverageTest` не трогались: они доказывают набор сценариев, а не лишнюю работу в запросе. Пакетная проверка `Visibility::bounded()` и потолок динамических прав остаются в `02-proposals.md`.
