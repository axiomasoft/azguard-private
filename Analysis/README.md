# Analysis

Заметки ветки `chore/latest-platform-and-faster-runs`. Это не план реализации и не каталог `plans/`.

Ревьюер может читать коммиты этой ветки вместе с этими файлами.

Итог независимого ревью и актуальные решения по всем пунктам: [05-review.md](05-review.md).
Ранние файлы сохранены как исторический анализ; их статусы уточняются итогом ревью.

| Файл | Что внутри |
|---|---|
| [01-run-shape.md](01-run-shape.md) | Замеры матрицы и прогонов. Что изменено в CI и что именно измерено. |
| [02-proposals.md](02-proposals.md) | Предложения, которые ломают совместимость или требуют отдельного решения. В код этой ветки они не входили, кроме чтения array-кэша через `all(false)`. |
| [03-code.md](03-code.md) | Что именно ускорено и собрано в коде после сужения матрицы. |
| [04-agent-sweep.md](04-agent-sweep.md) | Ход прогона двадцати агентов. Полный перечень, включая закрытое, в реестре. |
| [problems.md](problems.md) | Реестр всех проблем: закрытые, открытые, отложенные и не проверенные живьём. Ни одна находка прогона сюда не сжималась. |
| [05-review.md](05-review.md) | Проверка каждого пункта, дополнительные исправления, принятые ограничения и результаты qualification. |
