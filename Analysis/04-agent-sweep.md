# Прогон двадцати агентов

Дата: 2026-11-13. Ветка `chore/latest-platform-and-faster-runs`. Агенты только читали дерево. Полный текст каждой находки, со строками и статусом, лежит в [problems.md](problems.md). Этот файл только говорит, какие направления агенты закрыли пустыми и что из их списка вошло в коммиты.

Публичная поверхность относительно `main` не изменилась, кроме уже зафиксированного пола Illuminate `^13.0` и обещания MySQL 9.7 / PostgreSQL 18. Манифесты, ключи конфигурации и типы исключений те же.

## Где дыр не нашли

| Направление | Итог |
|---|---|
| Дубли между Folder, Relation и Gate | Одинаковых кусков от 12 строк нет. Похожие проверки `#[PolicyFor]` и `#[Decides]` различаются условиями. |
| Запись грантов | Схема полей строится один раз на вид. Запись без валидатора не коммитится. |
| Журнал аудита | Prune удаляет не больше 1000 id своей панели старше срока. |
| Провайдеры и Octane | Панель, актор и тенант — scoped. Синглтоны не держат пользователя первого запроса. |
| Поглощённые исключения | `catch (Throwable)` не превращает ошибку в allow и не снимает фильтр видимости. |
| SQL под MySQL 9.7 и PostgreSQL 18 | В коде нет конструкции, которую эти версии снимают. Контейнеры по-прежнему не стартовали, поэтому это не живой прогон. |
| Очередь и генераторы | Секретов по умолчанию нет, `unserialize` в этом срезе нет, `php artisan` запускается списком аргументов, не оболочкой. |

## Вошло в код

- Класс `#[CheckPermission]` больше не имеет второй формы «для Laravel без атрибутов контроллера». На 13.0–13.39 атрибут `Middleware` есть. Обход родителя на 13.0–13.4 остаётся в `RouteChecks`.
- `azguard.discovery.*` принимает только сегменты-идентификаторы. `../tmp` и `Roles;Exit` отклоняются и ядром, и генератором. Вложенное `Abilities/Perms` по-прежнему годится.
- Неиспользуемый `MakeCommand::file()` удалён.
- Пакетная проверка scope собирает структурный запрос тем же `structural()`, что и одиночная.
- Doctor читает материал подписи кэша один раз за прогон, а не на каждую Redis-панель. Находки те же: результат используется только для Redis.

Проверено: `ConfigSectionsTest` 10 passed, генератор прав и соседние конфиг-тесты 40 passed до добавления отказа `..`.

## Не вошло: меняет поведение

Эти пункты не чинились в этом прогоне. Каждый меняет то, что видит приложение.

- Страница `ManageRelatedRecords` не сужает таблицу через `visible()`, в отличие от relation manager. Секретная связанная строка остаётся на странице.
- `boot` страницы Filament выполняется до `canAccess()`. Doctor успевает отработать до 403.
- Relation manager, добавленный в рантайме без трейта, не режется на `mount`, в отличие от виджета.
- Не-editable колонка и запись-не-модель на enforced-таблице не получают 403 на `updateTableColumnState`.
- Bulk delete/restore возвращается раньше проверки явных ключей, если действие подменено.
- `azguard.panel` не закрывает маршрут вне панели, у которого родительский `#[CheckPermission]` маршрутизатор 13.0–13.4 не прочитал. Doctor только сообщает.
- Выключенная проверка атрибута (`except`) при выключенном strict mode пропускает действие. Тест это фиксирует как 200.
- `PanelContext::leaving()` возвращает `CurrentPanel`, но оставляет скрытый `azguard.panel` в контексте. Следующий job из позднего слушателя может унаследовать панель.
- `matchesMany()` в scopes считает тенант по копии в witness и не вызывает `tenantOf()` строки. Одиночный `matches()` вызывает. Пакет может разрешить то, что одиночная проверка запретит.
- `IdentityColumns::scopeConstraint()` склеивает имена в DDL. Сейчас туда приходят константы. Публичный SPI теоретически может передать произвольную строку.
- `tenant_id` журнала не проходит `canonicalKey()`, в отличие от subject и actor. `7` и `007` сольются в bigint.
- Кэш экземпляров политик и evaluator на вклад меняет allow/deny: сегодня каждый вклад получает новый объект.
- Общий список контекстов видимости перечитывается на каждую ветку вклада. Схлопывание меняет SQL.
- Один `SELECT` вместо `chunkById` у свидетелей DatabaseSource сохранит те же строки, но сменит форму запроса. Не делалось без прогона движков.
- Семян паритета меньше восьми делать нельзя без потери доказательства. Вложенные Pest-процессы матрицы возможностей можно сгруппировать по файлам, не выкидывая имена. Это отдельная правка тестов.
