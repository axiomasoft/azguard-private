# Известные ограничения

Это актуальные границы поддержки для кандидата 1.0. Шаги перехода приведены в
[руководстве по обновлению](./upgrading.md).

- **СУБД:** заявленный профиль точной идентичности scope — PostgreSQL 16+,
  SQLite 3.35+ и MySQL 8.0.13+ (не MariaDB) с InnoDB, страницами 16 КиБ и
  форматом строки `DYNAMIC` или `COMPRESSED`. MariaDB и MySQL с меньшими
  страницами не поддерживаются без отдельной проверки реального DDL. Миграция
  `000006` отклоняет такой профиль до изменения схемы.
- **API snapshot:** `ApiBoundaryTest` фиксирует помеченный `@api` контракт core.
  Для Filament и context ещё нет аналогичных reflection snapshots; проверяйте
  их публичную поверхность при изменениях.
- **Старая wildcard-грамматика:** `features.wildcard_permission=true` остаётся
  устаревающим совместимым режимом на один цикл. Новым интеграциям нужен
  стандартный matcher с границами сегментов.
- **Headless-настройка:** режим без панелей с ослабленной проверкой не
  поддерживается. Используйте минимальную настройку панели; strict-проверка
  остаётся закрытой при ошибке.
- **Тестовые дубли:** глобальный `Event::fake()` подавляет listeners, через
  которые `AzGuard::fake()` записывает события грантов. Для assertions этих
  событий оставьте их настоящими.
