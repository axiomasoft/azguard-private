# P04b — visibleTo без выдач возвращает пусто

**Probe:** P04b
**Finding:** N04
**Owning item:** PLAN2.P4.12
**Scenarios:** V31
**Defect in 0.3:** Пользователь без scoped-строк видел все три проекта: фильтр применялся только при наличии выдач. Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditProbesTest.php`, `it('P04b: an authenticated user with no scoped rows sees every row')`.
**Required behavior:** Пользователь без выдач и без глобального права получает пустой результат.
**Status:** pending

## Сценарий на целевом API

```php
Project::factory()->count(3)->create();

$visible = AzGuard::panel('seller')->visibility()->visibleTo(Project::query(), subject: $outsider, permission: ProjectPermission::View);

expect($visible->count())->toBe(0);
```
