# P10 — Тёплый кэш: десять проверок — один запрос версии

**Probe:** P10
**Finding:** N17
**Scenarios:** V19
**Defect in 0.3:** Десять проверок с тёплым request-кэшем выполняли десять `SELECT` ревизии состояния (`az_guard_permission_state`). Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditProbesTest.php`, `it('P10: ten checks of a warm request cache still issue ten revision SELECTs')`.
**Required behavior:** При тёплом кэше и `state_refresh = request` десять проверок дают один запрос версии состояния; повторное чтение выдач в запросе — 0 запросов к DB authority (бюджет D44).
**Status:** covered: tests/Regression/P10Test.php::P10: ten warm request checks read one state and no DB grants

## Сценарий на целевом API

Тест прогревает persistent raw cache через `Authorizer::decide`, сбрасывает scoped request instances и затем выполняет десять проверок с `state_refresh = request`. Считает отдельно SELECT `azg_panel_state` и SELECT обеих таблиц выдач: ровно один state read и ноль повторных reads выдач. Запросы live subject/policy/membership не входят в бюджет DB authority.

Cold coherent fence и режим `state_refresh = check` покрыты `tests/Feature/Authorization/Cache/RefreshModesTest.php`.
