# P01c — Одно правило выбора панели для ключа чужой панели

**Probe:** P01c
**Finding:** N01
**Owning item:** PLAN2.P2.2
**Scenarios:** V64, V49
**Defect in 0.3:** `hasPermission('admin.users.delete')` без панели оценивался по набору панели по умолчанию (`test`) и разрешался её wildcard, хотя ключ принадлежит `admin`. Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditProbesTest.php`, `it('P01c: hasPermission() evaluates a foreign-panel key against the default panel set')`.
**Required behavior:** Ключ никогда не оценивается по набору чужой панели: панель выбирает единое правило, и трейт, фасад, Gate, Blade, `azguard.can`, `decideMany` и CLI выбирают одну и ту же панель.
**Status:** covered: tests/Regression/P01cTest.php::resolves a key of the admin panel to admin and never to the default panel

Уровень `PanelResolver` закрыт P2.2: ключ `admin:users.delete` и имя с префиксом `admin.users.delete` выбирают панель `admin` при default-панели и текущей панели `test`. Сквозной сценарий ниже — acceptance V64 пунктов-адаптеров (трейт P5.1, фасад P6.1, Gate P4.11): каждый вход обязан идти через resolver.

Фасадные строки V64 закрыты P6.1 и covered тестом `tests/Regression/P01cTest.php::P01c answers a key of the backoffice panel from backoffice in the trait, the facade and the panel access`: `AzGuard::check`, `AzGuard::panel(...)->for(...)` и `AzGuard::panel(...)->decide` отвечают по той же панели, что трейт; ключ чужой панели во `for()`/`decide()` панели — `ConflictingPanelException`, а не переключение панели.

## Сценарий на целевом API

```php
// у субъекта суперадмин-роль только в панели test; default панель — test
$user->guard('test')->grantRole('super');

expect($user->hasPermission('admin:users.delete'))->toBeFalse()                 // панель admin из ключа, права там нет
    ->and($user->hasPermission(AdminUserPermission::Delete, guard: 'admin'))->toBeFalse()
    ->and(AzGuard::check($user, 'admin:users.delete'))->toBeFalse()
    ->and(Gate::forUser($user)->allows('admin:users.delete'))->toBeFalse();
// ни один вход не отвечает по набору панели test
```
