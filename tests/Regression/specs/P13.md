# P13 — Опечатки в данных отклоняются, а не молча сохраняются

**Probe:** P13
**Finding:** N14
**Owning item:** PLAN2.P5.2
**Scenarios:** V21
**Defect in 0.3:** `assignRole('edtor')` проходил молча без выдачи, а грант с опечаткой в ключе сохранялся и не действовал. Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditProbesTest.php`, `it('P13: assignRole() with an unknown role and a grant of an unknown key both "succeed"')`.
**Required behavior:** Неизвестная роль даёт `UnknownRoleException`, неизвестное право — `UnknownPermissionException`; ничего не сохраняется.
**Status:** pending

## Сценарий на целевом API

```php
expect(fn () => $user->guard('admin')->grantRole('edtor'))->toThrow(UnknownRoleException::class)
    ->and(fn () => $user->guard('admin')->grantPermission('admin:orders.veiw'))->toThrow(UnknownPermissionException::class)
    ->and($user->guard('admin')->roleGrants())->toBeEmpty()
    ->and($user->guard('admin')->permissionGrants())->toBeEmpty();
```
