# P06b — Контекст без поддержки в панели не превращается в глобальный allow

**Probe:** P06b
**Finding:** N06
**Owning item:** PLAN2.P4.6
**Scenarios:** V13
**Defect in 0.3:** Без пакета `azguard-context` `hasPermission(..., $context)` молча отдавал глобальный allow, а `hasPermissionIn` по тому же контексту отказывал. Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditProbesTest.php`, `it('P06b: hasPermission(..., $context) falls back to the global answer while hasPermissionIn() denies')`.
**Required behavior:** Область, которую панель не принимает, даёт отказ с причиной `DecisionReason::AssignmentScopeNotAccepted`, а не глобальный allow; все входы отвечают одинаково.
**Status:** covered: tests/Regression/P06bTest.php::P06b consistently rejects an unsupported explicit context instead of global allow

## Сценарий на целевом API

```php
$user->guard('cabinet')->grantRole('viewer');   // глобальная выдача; панель не объявляла тип 'workspace'

$workspace = AssignmentScopeRef::of('workspace', 42);

expect($user->hasPermission(OrderPermission::View, on: $workspace, guard: 'cabinet'))->toBeFalse()
    ->and($user->guard('cabinet')->decide(OrderPermission::View, on: $workspace)->allowed())->toBeFalse();
// причина отказа — AssignmentScopeNotAccepted ('context_not_accepted')
```
