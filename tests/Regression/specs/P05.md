# P05 — Неквалифицированный ключ без панели не даёт тихий отказ

**Probe:** P05
**Finding:** N05
**Owning rationale:** Колонка Probe досье относит P05 к P2.2 (V65) и P8.1 (V60); пункт P2.2 вводит правило выбора панели и `PanelNotResolvedException`, P8.1 только проверяет сценарий моста.
**Owning item:** PLAN2.P2.2
**Scenarios:** V65, V60
**Defect in 0.3:** Вызов моста Vaulter в форме `hasPermissionIn('project', 7, 'post.view')` (неквалифицированный ключ, `panelId = null`) отказывал при существующем гранте на `test.post.view`. Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditContextProbesTest.php`, `it('P05: hasPermissionIn() with an unqualified key and panelId null denies although the grant exists')`.
**Required behavior:** Имя права без панели в приложении с несколькими панелями и без панели по умолчанию бросает `PanelNotResolvedException`, а не молча отказывает; с явной панелью та же выдача разрешается.
**Status:** pending

## Сценарий на целевом API

```php
$project = AssignmentScopeRef::of('project', 7);
$user->guard('cabinet')->grantPermission(OrderPermission::View, on: $project);

expect(fn () => $user->hasPermission('orders.view', on: $project))
    ->toThrow(PanelNotResolvedException::class)
    ->and($user->hasPermission('orders.view', on: $project, guard: 'cabinet'))->toBeTrue();
```
