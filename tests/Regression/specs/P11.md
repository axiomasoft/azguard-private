# P11 — События изменений: после commit, без повторов

**Probe:** P11
**Finding:** N11
**Owning item:** PLAN2.P5.4
**Scenarios:** V34
**Defect in 0.3:** `HasDirectGrants::grant()` не отправлял событие, повторная выдача без изменений отправляла, а событие срабатывало внутри транзакции. Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditProbesTest.php`, `it('P11: trait grant() emits no event, a no-op re-grant emits one, and events fire inside the transaction')`.
**Required behavior:** Каждое изменение отправляет событие после commit и не при откате; повтор без изменения (`Unchanged`) события не даёт; `eventId` уникален; payload не содержит моделей.
**Status:** pending

## Сценарий на целевом API

```php
$levels = [];
Event::listen(AzGuardChangeEvent::class, function () use (&$levels): void {   // класс события определяет P5.4
    $levels[] = DB::transactionLevel();
});

$first = $user->guard('admin')->grantRole('support');
$again = $user->guard('admin')->grantRole('support');

expect($first->status->name)->toBe('Applied')       // ChangeResult::status, тип определяет P5.2
    ->and($again->status->name)->toBe('Unchanged')
    ->and($levels)->toBe([0]);   // одно событие, отправлено после commit
```
