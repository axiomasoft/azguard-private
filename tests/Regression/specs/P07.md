# P07 — Ключ области однозначен и ключи кэша не пересекаются

**Probe:** P07
**Finding:** C01
**Owning item:** PLAN2.P1.1
**Scenarios:** V01, V04
**Defect in 0.3:** Выдача в контексте `(workspace, "a:7")` отдавалась из durable-кэша для `("workspace:a", 7)`: две разные области сводились к одной строке ключа; без кэша решение было отказом. Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditContextProbesTest.php`, `it('P07: a grant in context (workspace, "a:7") is served for context ("workspace:a", 7) from the durable cache')`.
**Required behavior:** `AssignmentScopeRef::key()` однозначен: тип с `:` отклоняется, `of('w', 7)` и `of('w', '7')` совпадают; digest ключей кэша различен для разных `(panel, subject, contexts)`.
**Status:** pending

## Сценарий на целевом API

```php
expect(fn () => AssignmentScopeRef::of('workspace:a', 7))->toThrow(InvalidAssignmentScopeException::class)
    ->and(AssignmentScopeRef::of('w', 7)->key())->toBe(AssignmentScopeRef::of('w', '7')->key())
    ->and(AssignmentScopeRef::of('workspace', 'a:7')->key())
        ->not->toBe(AssignmentScopeRef::of('workspace', 'a')->key());

// property V04: для 1e5 случайных (panel, subject, contexts) digest ключа кэша различен
```
