# P08 — DB-роль даёт право и в scoped-назначении

**Probe:** P08
**Finding:** N08
**Owning rationale:** Колонка Probe досье относит P08 к V15 (P4.1, property-тесты пайплайна); возможность DB-роли в scoped-назначении вводит P4.4 (`DatabaseSource`), поэтому owning item — P4.4, а V15 остаётся сценарием.
**Owning item:** PLAN2.P4.4
**Scenarios:** V15
**Defect in 0.3:** DB-роль давала право при глобальной выдаче, но `hasScopedPermission` отказывал для той же роли в scoped-назначении; шаблоны в scoped-режиме игнорировались. Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditProbesTest.php`, `it('P08: a DB role grants globally but not when assigned scoped; patterns are ignored when scoped')`.
**Required behavior:** Одна и та же роль `DatabaseSource` даёт одинаковые права глобально и в точной области назначения, включая шаблоны; вне области прав нет.
**Status:** pending

## Сценарий на целевом API

```php
$user->guard('seller')->grantRole('store-manager', on: $store);   // роль DatabaseSource с правом и шаблоном 'seller.orders.*'

expect($user->hasPermission(SellerOrderPermission::Cancel, on: $store, guard: 'seller'))->toBeTrue()
    ->and($user->hasPermission('seller:orders.refund', on: $store, guard: 'seller'))->toBeTrue()   // шаблон
    ->and($user->hasPermission(SellerOrderPermission::Cancel, on: $otherStore, guard: 'seller'))->toBeFalse();
```
