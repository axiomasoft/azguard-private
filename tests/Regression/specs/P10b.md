# P10b — Транзакция видит свои изменения, отзыв виден после commit

**Probe:** P10b
**Finding:** N17
**Owning item:** PLAN2.P4.8
**Scenarios:** V18
**Defect in 0.3:** Внутри любой транзакции на соединении кэш обходился, и источники перечитывались на каждой проверке (5 проверок = 5 чтений ролей). Тест: `audits/2026-09-29-audit/opus/evidence/probes/OpusAuditProbesTest.php`, `it('P10b: inside any transaction on the connection the cache is bypassed and sources re-query')`.
**Required behavior:** Внутри незакоммиченного изменения видно своё изменение; после commit отзыва новая проверка (новый запрос) отказывает, а при `state_refresh = check` отказывает и в том же запросе.
**Status:** covered: tests/Regression/P10bTest.php::P10b supported root sees its own changes and committed revoke survives a new request

## Сценарий на целевом API

Поддержанный root начинается через `Authorizer::withinAuthorityTransaction()` или корневой
`Storage::mutate()`. В callback выдача/отзыв видны немедленно; tentative набор не публикуется.
Вход helper внутри неизвестной внешней транзакции отклоняется. После commit отзыва новый
request отказывает; rollback восстанавливает прежний набор и version.
